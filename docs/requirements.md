\# DevPilot AI - Product Requirements



Version: 1.0.0

Status: Proposed MVP

Project: DevPilot AI



\## 1. Product Vision

DevPilot is cloud-hosted, AI-powered software engineering assistant.



It helps developers investigate source-code issues 

through retrieval-augmented generations (RAG) 

and stateful multi-agent workflows.



\## 2. Primary Goals

\- Build a working, evidence-grounded RAG pipeline.

\- Orchestrate investigations using LangGraph.

\- Provide a usable React and TypeScript frontend.

\- Deploy a publicly accessible demo to Azure.

\- Minimize cloud costs and prevent uncontrolled AI usage.

\- Provide reproducible tests and evaluation results.



\## 3. Target Users



\### Developer

Wants to understand a repository, investigate bugs,

and inspect possible fixes.



\### Project Owner

Wants to run authenticated live investigations,

inspect system metrics, and control spending.
